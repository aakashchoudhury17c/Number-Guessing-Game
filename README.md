# Number Guessing Game

A simple Java console game where the player guesses a randomly generated number between 1 and 100.

## Features
- Random number generation
- Hints for guesses that are too high or too low
- Tracks the number of valid guesses
- Handles invalid input

## Technologies Used
- Java

## How to Run
1. Compile: `javac NumberGuessingGame.java`
2. Run: `java NumberGuessingGame`
